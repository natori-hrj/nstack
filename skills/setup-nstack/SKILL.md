Identify the active harness and deployment scope. Open its adapter instructions before resolving discovery, effective permissions, roles, model and reasoning effort, and provider access. nstack ships the [Codex adapter](../../docs/codex.md); if that document is outside the installed skill bundle, locate it in the source checkout or ask for the adapter location.

Check the installed role configuration and current host capabilities. Independently record configured routes, advertised capabilities and completed model responses. Use special access only when explicitly selected for authorized work and available under the active account and session. If a selected role or its capabilities are unavailable, report the blocker and obtain an explicit model choice before substitution.
