---
name: arena
description: Compare independent approaches to the same task using shared acceptance checks.
---

Freeze the brief, base revision, constraints and check before starting. Use the `swarm` isolation rules for alternative writers. Give contenders identical acceptance criteria and a bounded budget. Compare demonstrated behavior, patch size and maintenance cost. Use an independent read-only reviewer if it resolves a material disagreement. Report the evidence and let the operator select the patch. Keep competing worktrees until authorized cleanup.
