name: natori-mode
description: Route a rigorous engineering task to one nstack workflow.
---

Inspect the request, repository instructions, worktree state and existing verification commands. Define observable behavior and an executable acceptance check.
Read the applicable playbook in this directory. For investigation, stay read-only and trace the contract. For design uncertainty use $architect.
When delegation is useful and authorized, use the configured implementation, defensive security or independent review role. For model selection and Daybreak access, follow $setup-nstack. If a required route is unavailable, report the blocker.

Use $blast-radius before broad changes. Choose $tdd when a test-first regression or feature check will clarify the contract. Use $interrogate when independent verification materially changes confidence. Finish once acceptance evidence and limitations are recorded.

Before delivery record the base and exact candidate revision, acceptance command and result, mandatory checks, reviewer and reviewed revision, and any blocked or missing evidence. For an uncommitted candidate identify the full diff and untracked inputs. When the candidate changes, rerun affected acceptance and review checks and run required gates on the final revision. Keep local evidence distinct from CI or provider evidence. Follow project authorization for routine branch delivery and gated remote actions.
