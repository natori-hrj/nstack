name: natori-mode
description: Route a rigorous engineering task to one nstack workflow.
---

Inspect the request, repository instructions, worktree state and existing verification commands. Define the outcome and an executable acceptance check.
Read only the applicable playbook in this directory: bug-fix, feature, refactoring, babysit, autopilot-stack, session-pickup, or pause-safely. For investigation, stay read-only and trace the relevant contract. For design uncertainty use $architect.
When delegation is useful and authorized, select nstack_implement for general work, nstack_security for defensive security changes, or nstack_review from a read-only parent for independent judgment. If the requested route is mandatory and unavailable, stop that task and report the blocker.

Use $blast-radius before broad changes, $tdd for meaningful behavioral regressions, and $interrogate when independent verification changes confidence. Read the relevant principle directly when it resolves a decision. Finish once acceptance evidence and remaining limitations are recorded.
