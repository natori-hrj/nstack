# nstack v0.3.0

## 日本語

- 観測できる受け入れ条件を先に定義し、TDD は必要な場面で使います。共有ワークフローはホスト固有のアダプターを通じて実行します。
- Codex で独立した読み取り専用レビュー、候補 SHA と証跡の照合、最大2巡の自動修正に対応しました。`--review-only` と `--review-first` で既存候補を確認できます。
- 標準の防御ロールは Sol です。Daybreak Blue は明示選択とアクセス確認が必要です。モデルと推論強度はロールごとに設定できます。
- 管理済みの直接導入はスナップショットで更新・切り戻しができ、個人のエージェント TOML を保持します。
- Codex CLI 0.172.0 で検証しています。他のホストの実動は未検証です。認証なし CI と認証済みモデルレビューの証跡は別に記録します。

[導入・更新・切り戻し・レビューのコマンド](https://github.com/natori-hrj/nstack/blob/v0.3.0/docs/v0.3.0.md)

## English

- Define observable acceptance before implementation and use TDD where it helps. Shared workflows delegate host-specific operations to an adapter.
- The Codex adapter supports independent read-only review, exact candidate evidence and up to two remediation rounds. Use `--review-only` or `--review-first` for an existing candidate.
- Sol is the standard defensive role. Daybreak Blue requires explicit selection and verified access. Models and reasoning effort are configurable by role.
- Managed direct installations support snapshot upgrades and rollback while preserving personal agent TOMLs.
- Verified with Codex CLI 0.172.0. Other harnesses remain unverified. Offline CI and authenticated model review are recorded separately.
